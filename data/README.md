# Data

`raw/5year.arff` - *Polish Companies Bankruptcy* dataset, 5th-year file: financial ratios from the
5th year of the observation window, labelled with bankruptcy status **one year later**
(5,910 companies, 410 bankruptcies). This is the 1-year default horizon used by the model.

`raw/attribute_definitions.csv` - definitions of the 64 financial ratios (Attr1-Attr64).

Source: Tomczak, S. (2016). UCI Machine Learning Repository -
https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data
